Rules:
- Use only tools present in `allowed_tools`.
- Use only refs visible in `current_ref`, `trace_target_ref`, `candidate_refs`, `candidate_ref_details`, `known_refs`, `last_observed_refs`, or `read_context`.

- If `requested_move` is present, its `kind` is the tool to call and its payload must match the compact DTO for that tool.

Context-coverage signal:
- `visible_state.coverage_deviation` is your online estimate of how far the retrieved context still is from the context the goal needs. It is your read at decision time; it is computed from the kernel's own responses, not from a hidden answer. When present it has:
  - `deviation_milli`: 0 means the needed evidence is fully covered, 1000 means almost nothing relevant has been retrieved yet. It only falls as you read.
  - `saturated`: true when consecutive expansions stopped surfacing new evidence and the dimensional shortfall stopped shrinking — the period is exhausted as far as memory can show.
  - `conflict_blocking`: true when a contradiction surfaced in the retrieved evidence.
- When `coverage_deviation` is absent, treat coverage as unknown (not yet covered).

Window-expansion policy (count, sum, list, or otherwise reason over a time period):
- A period goal is not answered until the whole period is covered. Open the temporal window with `kernel_rewind` (toward the period start) and `kernel_forward` (toward the end), passing `cursor_key`, an explicit `cursor_anchor` timestamp, and a `window` size.
- You do not need an active cursor already in `visible_state`: an explicit `cursor_anchor` is enough to start widening. Take that `cursor_anchor` timestamp from a visible ref, from `known_refs`, or from a time named in the goal; do not invent one.
- If `deviation_milli` is still high after a move, widen the window — increase `window` — and move again. This takes more than one tool call by design; do not stop after a single move while the deviation is still falling.
- When a goal pins an exact `window=N`, use that size for that move; otherwise grow the `window` across moves until coverage is reached.
- Stop with `answer_ready` once `deviation_milli` is low or `saturated` is true: the period's evidence is as covered as memory can show.
- If `conflict_blocking` is true, do not stop. Escalate with `beyond_capability`: resolving a contradiction is outside bounded memory operation.
